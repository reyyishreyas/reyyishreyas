## 🚀 Projects

### 🔎 [Research Paper Analyst Agent](https://github.com/reyyishreyas/research-agent-rag)
Agentic RAG system built with **LangChain + Google Gemini** — it reasons about a query first, then autonomously picks between retrieval, summarization, or comparison tools to answer questions across a corpus of research papers. Chunked + embedded with `sentence-transformers`, stored in a local **FAISS** index, served through a Streamlit chat UI with source-cited answers.
<br>`Python` `LangChain` `Gemini API` `FAISS` `Streamlit`

### ♟️ [ChessMind AI](https://github.com/reyyishreyas/ChessMind_AI)
A chess bot that dynamically adjusts its Elo mid-game based on how you're playing, instead of sticking to one fixed difficulty.
<br>`TypeScript` `Game AI`

### 🏸 [Smart Fixture](https://github.com/reyyishreyas/smart_fixture)
Automates tournament management — smart fixture generation, multi-court scheduling, same-club avoidance, and secure umpire score submission, with winners auto-advancing and live leaderboards.
<br>`TypeScript`

### 🎓 [Samarth](https://github.com/reyyishreyas/Samarth)
A project built for Smart India Hackathon (SIH).
<br>`JavaScript`

### 💰 [Salary Predict AI](https://github.com/reyyishreyas/Salary_Predict_AI)
A tool for predicting salaries from input features.
<br>`HTML`

### 📉 [Churn Predictor](https://github.com/reyyishreyas/churn_predictor)

<br>`TypeScript`
