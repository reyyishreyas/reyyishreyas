## 🎯 Current Focus

```
├─ ML systems that adapt in real time — dynamic difficulty & skill
│  estimation driven by trained models, not fixed rules
├─ Ensemble pipelines (stacking, boosting, bagging) for tabular
│  prediction problems
├─ Reading the internals of scikit-learn & XGBoost instead of
│  treating them as black boxes
└─ Agentic RAG — LLM tool-selection over retrieval, summarization
   and comparison, grounded in a local vector index
```

## 🌱 Open Source

Looking to contribute to ML/DL projects where I can work on model training pipelines and evaluation tooling, ensemble method implementations, and sequence model (LSTM/GRU) components and their documentation.

I learn a codebase by running it, breaking it, and reading the tests — not by skimming the README. First contributions I look for: failing tests, unclear docs, and missing edge-case handling in data preprocessing.

Based in India (IST) · Responsive on GitHub issues and PRs.
